## 📖 About

Hell is Us by Rogue Factor (2025) is a third-person action adventure with no map, no waypoints, and no quest markers. You play as Remi in a country torn apart by civil war and supernatural infestation. It fully commits to the philosophy of player discovery over handholding.

## ⚠️ Problems Without Trainer

| Problem | Status |
|---------|--------|
| Zero waypoints require organic investigation that confuses most players initially | ✅ Solved |
| Fuel for the motorbike exhausts during long cross-country traversal sessions | ✅ Solved |
| Entity combat requires learning specific vulnerability windows from observation | ✅ Solved |
| Village trust meters decay without regular return visits impeding questlines | ✅ Solved |
| Dark zone navigation without light sources leads to unavoidable entity ambushes | ✅ Solved |

## ✅ Solution

The **Hell is Us Trainer** solves all these issues, giving you complete control so you can focus on enjoying the game.
